pcbview

Working — first version

KiCad boards on the web: a schematic / PCB / 3D viewer after Altium 365’s, generated from the board files by KiCad’s own exporters. Pulled out of servodrive’s project pages so any board here can have one.

Where it stands

One command, python3 -m pcbview build pcbview.toml, turns a KiCad project into a static site: every schematic sheet as kicad-cli plots it, every copper layer plotted in KiCad’s own coordinates and stacked in register (with silkscreen and fab overlays), and the assembled board as a GLB cut from ~30 MB to ~8. Click a part on the PCB or in 3D for its value, LCSC number, footprint, position and the net on every pin. A board can be read straight out of git at a tag, so a page can pin the design that was fabricated. Applied first to rp2350-motor-controller rev A (pcbview.toml at that repo’s root, served as review/viewer/: proj url rp2350-motor-controller + viewer/).

Examples served here: three of KiCad’s demo projects (hierarchical sheets, a sheet used twice, an 8-layer board) and servodrive’s board S, the board the viewer was written for, rebuilt through pcbview as a parity check.

Working

  • Project registered on port 8037
  • SCH tab: hierarchy walked from the files, one plot per sheet instance, PDF
  • PCB tab: any outline (pcbnew’s own polygon), pcbnew coordinates, r/θ on round boards
  • 3D tab: model paths resolved (KiCad 6–8 variables, VRML→STEP, project folder), stand-ins from config
  • Nested STEP assemblies flattened automatically; unmodelled parts drawn as courtyard boxes
  • Part pane shared by PCB and 3D, selection kept across tabs
  • git = "tag" boards; quick mode with no config
  • rp2350-motor-controller rev A: 259 of 291 parts modelled, 8 boxed
